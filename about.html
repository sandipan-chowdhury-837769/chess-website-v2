Website Info

This is a fully functional, static chess application. It utilizes the powerful Stockfish WebAssembly (WASM) engine to calculate moves and evaluate positions entirely locally in your browser.

Features include dynamic ELO scaling, real-time win probability analysis, an interactive Match Review system, and an integrated move classification engine (Brilliant to Blunder).
